# Task API
A REST API built with Node.js, Express, and MySQL.

## Features
- Create a task
- Get all tasks
- Get a task by ID
- Update a task
- Delete a task

## Technologies
- Node.js
- Express.js
- MySQL
- MySQL2
- Postman

## Setup
1. Clone the repository.
2. Run 'npm install'.
3. Create a '.env' file using '.env.example'.
4. Run the SQL script in 'database.sql'.
5. Start the server with 'npm start'.

## Base URL
http://localhost:3000/v1/tasks
